📚 Quick Start

All demos connect to the local Heat server emulator. Open multiple browser windows or tabs to test multi-user interactions.

Use the ?channel=YOUR_ID URL parameter to test different channels:

/test.html?channel=12345

🛠️ For Developers

Use the heat-client.js library in your own pages to connect to the emulator. See the demo source code for examples.

Server logs and connection info are visible in your terminal.
